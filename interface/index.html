How iCKB works

Put CKB into NervosDAO and get iCKB back. iCKB keeps the DAO position easy to move, so you do not have to manage deposit cycles by hand.

Why iCKB exists

NervosDAO lets CKB holders lock CKB and receive DAO compensation. A direct DAO deposit normally waits through about 30 days before it can exit. iCKB aims to make that DAO position easier to move.

When you swap CKB to iCKB, the protocol puts deposits into a shared pool. When you swap back, it can use CKB that is ready in the pool, or other liquidity when it exists.

The pool is many DAO deposits moving through the cycle together. You do not have to wait for your own deposit if a ready pool deposit is available.

iCKB is a CKB token, so compatible wallets and apps can move it like other xUDT assets.

Audit status

The iCKB L1 scripts are the on-chain rules for deposits, minting, and withdrawals. People with deep Nervos L1 experience reviewed them, a Scalebit audit checked them, and a later security review checked the release binaries.

The contract repo also has the tests used in that review. That does not remove risk, but it makes the core rules public and testable.

This web app is separate from the contracts. Review its web app source code if you want, and only sign transactions you understand.
