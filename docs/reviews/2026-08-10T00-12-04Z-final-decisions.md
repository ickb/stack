Authoritative record for the rewrite. Consolidates and, where stated, amends the five 2026-08-09 documents (whole-repo-parallel-review, design-blueprint, overhaul-decisions, less-is-more-addendum, best-shape), the critic pass, and the July-corpus salvage. ## 1. Target architecture

- **One published package: `@ickb/sdk`, single entry point.** Directories `core/`, `order/`, `dao/`, `shared/` are comprehension boundaries, not packages. `shared/` is the ex-utils subtree (root-exportable helpers, incl. `EntityBase`); domain-directory public symbols are exported from the root barrel. (Reconciled with amendment §7.) No subpath exports (may be added additively later). Rationale: the order script's on-chain weakness (see §5 caveat) removes the generic-adoption thesis; per-entry-point costs, not per-package costs, were the real overhead.
- **Root export surface** (enforced by the committed api-extractor report): the Snapshot API (snapshot, result unions, SentTransaction, quoteConversion, completeTransaction), managers, `IckbError` + code union, and the community-bot capability floor — `OrderManager`, `Match`, `OrderGroup`, `OrderCell`, `Info`, `Ratio`, `convert`, `ickbExchangeRatio`, `ICKB_DEPOSIT_CAP`, `receiptPhase2Capacity`, `receiptCellFrom`, `ickbValue`, `IckbDepositCell`, `ReceiptCell`, `WithdrawalGroup`, `unique`, `availableOutputSlots`, `DAO_OUTPUT_LIMIT`, `MAX_DIRECT_DEPOSITS`, `DEFAULT_ORDER_FEE`, `DEFAULT_ORDER_FEE_BASE`, named bot reserve constant, `EntityBase`, and the per-entity `XBase` consts (B4 pattern, amendment §§7-8). This list resolves the internal-dirs-vs-floor contradiction flagged by the critic.
- **Ring surface resolution** (supersedes blueprint A5 `RingAnalysis`): no SDK ring aggregate. The SDK exposes the deposit pool with maturity data; the bot computes the one-window kernel in-app. The earlier "ring aggregate" invariant-export decision is superseded.
- **6 workspaces**: `packages/{sdk,node-utils,testkit}`, `apps/{bot,validation,interface}`. Bot and validation absorb their old packages and scripts layers (lib/cli directory split, depcruise-enforced); sampler dissolves into a testkit bin (CSV + `--fixtures` header dump).
- **Depcruise rules (3)**: sdk browser-safety (no node builtins); testkit never imported from `src/**`; oracle imports nothing from the implementation. (The former "internal/ never exported" rule is dropped per amendment §7 — the root barrel + committed api report are the export gate.) Superseded and retired: "sdk consumes only core/dao/order public surface" and the generic-tier purity rule (both die with the package merge). Asymmetric-ratio/fast-check testing stays regardless — its justification is now oracle honesty and C1-class regression, not a foreign-token warranty.
- **Versioning**: single `CHANGELOG.md`, changesets dropped. **Version number and npm-registry handling UNRESOLVED** — all five `@ickb/*` names have live history at `1000.0.82`; publishing `0.x` needs an explicit registry decision (deprecate 1000.x with pointer / accept ordering quirk / new name). Blocks only the publish step, nothing else.
- Tech: React + Vite + Tailwind + CCC connector kept in the interface; react-query, React Compiler/Babel, lazy-load machinery dropped. jscpd deleted. `Type=notify` systemd-native ops (launcher dissolved). 100% coverage kept, scoped to `src/**`, with the documented `src/cli/*` exclude (vitest cannot observe spawned children).

18. **Tester-signing exception — maintainer decision (2026-08-10, resolves review F-005)**: option A, documented testnet-only acceptance. The in-process tester's signing key IS readable-in-principle by the same-UID steering agent; this is accepted because the key is testnet-only and faucet-refillable (~zero monetary value), is never reused on mainnet (separate keys), and the worst case is validation disruption — while the alternative (a distinct-UID signing daemon) would spend a new component and IPC protocol to protect a nuisance-grade asset and re-complicate the in-process tester design. Conditions attached: the key flows keyring → process environment at spawn only (never files, never artifacts); it is rotated at soak-session end and on any suspicion; the Phase-4 mainnet-rejection tests make it useless against mainnet endpoints regardless. This is an explicit, scoped weakening of the "no agent key access" principle for this one testnet path; every other signer keeps the distinct-UID + systemd-credentials boundary (amendment §11), and the staged-cutover rollback pair includes the credential schema (amendment §3).
