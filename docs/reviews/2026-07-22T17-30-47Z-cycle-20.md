## New Simplification Candidates

These candidates are additional to cycle 19's backlog and preserve current observable contracts.

### Replace the role character machine with one exact regex

`scripts/live/config/generate-config-args.ts:3-10,167-215` implements a 1-32-character ASCII role grammar through four code-point constants and five helper functions. One anchored expression can preserve lowercase-first, lowercase/digit/separator body, no trailing separator, and the existing error/path/config contract while deleting that machinery. Predicate and regex agreed across 1,016 sampled boundary and invalid values. Add explicit one/32-character, leading/trailing separator, Unicode, and control-character cases before replacement.

### Use Node's native glob for script-test discovery

`scripts/run-node-tests.ts:1-54` recursively walks directories only to select sorted `scripts/test/**/*.ts` files excluding `support.ts`. Node 22.19's stable `globSync` can delete the recursive walker, filesystem wrappers, `Dirent`, and path import while preserving the explicit zero-test failure and the existing script entrypoint. Native discovery selected the same 33 files and ran the same 204 tests. Do not delete the wrapper: Node's test runner may otherwise succeed when a magic glob matches nothing.

### Give launcher child settlement one promise owner

`scripts/bot/launcher/runtime/process.ts:68-86,140-219` installs two `close` listeners and carries both `childResultPromise` and a separate `childClosePromise` through launch failure state. Cleanup can await the existing non-rejecting child-result promise when it only needs settlement, deleting `waitForChildClose` and the duplicate fields. Preserve error-before-close behavior, signal escalation, reaping before sink/lock close, and the exact terminal evidence order.

### Delegate private CKB formatting to the existing CCC dependency

`packages/node-utils/src/format.ts:1-25` duplicates fixed-point quotient, remainder, padding, and zero trimming. Private `@ickb/node-utils` already depends on CCC. Formatting the absolute bigint through `ccc.fixedPointToString` and restoring the sign can delete the local scale and formatter while preserving all 44 consumers' byte-visible strings. Directly passing negative sub-CKB values is unsafe because CCC places the sign incorrectly for that input; boundary tests must cover the absolute-value wrapper.

### Return quote text instead of a one-field object

`apps/interface/src/shared/quote.ts:10-47` returns `{ outputText }` solely for `apps/interface/src/view/formState.ts:30-48` to immediately project the field. Returning the string directly deletes the interface and allocations without changing rendered quotes, validation messages, editing placeholders, representability handling, or exception behavior. It is an app-local export with one production caller, not a published package contract; update the quote unit tests that currently lock `{ outputText }`, then run quote, form, typecheck, and interface-build tests.
